**Локальный open-source оверлей «всё в одном» для Path of Exile 1.** В одном portable `.exe` собраны проверка цен по `Ctrl+D`, локальная оценка тайника, трекер прибыли фарма (`chaos/hr`, `divine/hr`), экспорт для оптовой продажи и чат-макросы. Всё работает локально без Overwolf, сторонних серверов и облачной синхронизации.

## Почему Simple PoE Check?

- **Один лёгкий инструмент вместо трёх:** проверка цен в игре, трекер тайника и фарма, bulk-экспорт и макросы `/hideout` работают без лишних вкладок в браузере.
- **Никаких сторонних серверов:** запросы идут напрямую с вашего ПК в `pathofexile.com` и `poe.ninja`. Без телеметрии и чужих баз данных.
- **`POESESSID` не обязателен:** проверка цен по `Ctrl+D` работает сразу без логина и куки. `POESESSID` нужен только для сканирования вкладок тайника.
- **Прозрачная сборка из исходников:** GitHub Actions собирает portable `.exe` прямо из этого репозитория и публикует контрольные суммы `SHA256SUMS.txt`.

## Обязательные требования

Перед запуском **Simple PoE Check** проверьте настройки игры:

1. **Язык клиента Path of Exile должен быть английским (English).**
   Парсер читает текст предмета из буфера обмена (`Ctrl+C`). При русском или другом языке клиента названия предметов и модов не совпадут с англоязычной базой Trade API и `poe.ninja`.
2. **Режим экрана: Оконный на весь экран (Windowed Fullscreen) или Оконный (Windowed).**
   Оверлей не может отображаться поверх эксклюзивного полноэкранного режима (**Fullscreen**) в Windows.
3. **ОС:** Windows 10 / 11 (64-bit) для portable-версии.
4. **Права администратора (если нужно):** Если Path of Exile запущен от администратора, запускайте Simple PoE Check тоже от администратора. Иначе Windows блокирует перехват клавиш и привязку оверлея.

## Быстрый старт (Portable)

1. Скачайте актуальный `Simple-PoE-Check-*-portable.exe` со страницы [GitHub Releases](https://github.com/T58574/simple-poe-check/releases).
2. Положите `.exe` в любую удобную папку (например, `D:\Games\SimplePoECheck\`) и запустите двойным кликом.
   - *Примечание:* Так как у open-source сборки нет платной цифровой подписи, Windows SmartScreen может показать предупреждение *«Система Windows защитила ваш компьютер»*. Нажмите **Подробнее** -> **Выполнить в любом случае**.
3. При первом запуске автоматически откроется окно приложения. Откройте **Settings** и убедитесь, что выбрана нужная **Лига** (при первом старте активная лига подбирается автоматически).
4. Запустите Path of Exile (**на английском языке**, режим **Windowed Fullscreen**).
5. Наведите курсор на любой предмет в игре и нажмите `Ctrl+D`, чтобы узнать цену.
   - Приложение сворачивается в системный трей Windows (рядом с часами, кнопка `^`). Двойной клик по иконке в трее открывает окно Stash / Farm Tracker.

## Возможности

- **Проверка цен в игре (`Ctrl+D`)**
  - Мгновенные цены с `poe.ninja` для Валюты (включая стаки дешевле 1c), Фрагментов, Скарабов, Зверей, Гадальных карт, Уников, Камней умений и Карт.
  - Живой поиск через Path of Exile Trade API для редких (Rare), магических (Magic), расколотых (Fractured), с влиянием (Shaper/Elder/Conquerors/Eldritch) предметов и карт `Map (Tier N)`.
  - Поддержка расширенного описания модов (`Ctrl+Alt+C`), фильтры по тирам, разделение гибридных расколотых модов, расчёт DPS оружия и брони при Q20, фильтр качества (`Q%`) и сокетов/линков/цветов (`R`/`G`/`B`/`W`).
  - Встроенный ограничитель запросов (`PolicyRateLimiter`), читающий заголовки `x-rate-limit-*`, чтобы не ловить `429`.

- **Трекер тайника и фарма (`Ctrl+Space` или отдельное окно)**
  - **Оценка тайника:** сканирует только выбранные вами вкладки и оценивает их локально по `poe.ninja` в Chaos и Divine.
  - **Защита от рейт-лимита:** PoE Stash API жёстко ограничивает частоту запросов. Приложение само делает паузы между вкладками, ставит 15-секундный кулдаун между снимками и показывает текущую квоту (`Stash API X/Y`). Выбирайте только нужные вкладки и не обновляйте тайник слишком часто.
  - **Фильтры и сортировка:** поиск по названию, категории, вкладке, минимальной цене (`minItemChaos`), сортировка по любому столбцу и копирование названия кликом.
  - **Трекер фарма:** делайте снимки (Snapshots) до и после серии карт, чтобы видеть чистую прибыль, `chaos/hr`, `divine/hr` и топ выбитых предметов.
  - **Оптовая продажа (Bulk Selling):** агрегирует стакающиеся предметы по выбранным вкладкам с настраиваемым порогом цены и множителем (`85%`–`110%`), готовый текст для копирования.
  - **Отдельное окно (Pop-Out Window):** можно вынести рабочую область в обычное окно Windows и перенести на второй монитор.

- **Чат-макросы**
  - Настраиваемые горячие клавиши для `/hideout` (`F5`), `/kingsmarch` (`F6`), `@last` (`F7`), `/leave` (`F9`) и своих команд.

## Горячие клавиши по умолчанию

| Клавиша | Действие |
|---|---|
| `Ctrl+D` | Проверить цену предмета под курсором |
| `Ctrl+Space` | Открыть / скрыть окно Stash / Farm / Bulk |
| `Escape` | Закрыть активный оверлей |
| `F5` | `/hideout` |
| `F6` | `/kingsmarch` |
| `F7` | `@last` (ответить последнему написавшему) |
| `F9` | `/leave` |

Все клавиши можно изменить в **Settings**.

## Приватность и `POESESSID`

- Ваш `POESESSID` хранится **только локально** в `userData/config.json` и отправляется исключительно на `pathofexile.com` для чтения выбранных вкладок тайника.
- Снимки тайника и кэш `poe.ninja` / Trade хранятся локально на диске.
- Кнопка **Sign in (PoE)** открывает `https://www.pathofexile.com/login` в вашем системном браузере — скопируйте `POESESSID` из DevTools (`F12` -> `Application` -> `Cookies` -> `pathofexile.com` -> `POESESSID`).

## Решение проблем

- **По `Ctrl+D` ничего не появляется:**
  - Убедитесь, что в PoE выбран режим **Windowed Fullscreen** или **Windowed** (не обычный Fullscreen).
  - Убедитесь, что язык игры — **English**.
  - Если PoE запущена от администратора, перезапустите Simple PoE Check от администратора.
  - Проверьте поле **Game Window Title** в настройках (по умолчанию `Path of Exile`).
- **Ошибка 403 / Cloudflare при поиске на Trade:**
  - Укажите `POESESSID` в настройках или нажмите **Open in Browser** на карточке оверлея.
- **Не видно иконку в трее:**
  - Нажмите стрелку `^` на панели задач Windows и при желании перетащите иконку на панель задач.

## Разработка и сборка

Требуется Node.js 20+ (рекомендуется 22).

```bash
npm install
npm test
npm run build
```

Локальный запуск после сборки:

```bash
npx electron .
```

Сборка portable-версии для Windows:

```bash
npm run package:win
```

### Автоматический релиз на GitHub

Запушьте тег вида `v*` (совпадающий с версией в `package.json`) или запустите workflow **Release** вручную во вкладке GitHub Actions (`Actions -> Release -> Run workflow`):

```bash
git tag v0.1.0
git push origin v0.1.0
```

GitHub Actions прогонит тесты, соберёт `Simple-PoE-Check-<version>-portable.exe` на `windows-latest`, посчитает `SHA256SUMS.txt` и автоматически опубликует релиз.

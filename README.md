## Requirements

Before running **Simple PoE Check**, make sure your game is configured as follows:

1. **Path of Exile client language: English.**
   The item parser reads clipboard text generated by the game (`Ctrl+C`). Non-English client locales produce localized mod strings that will not match the English trade stat database.
2. **Display Mode: Windowed Fullscreen (Borderless) or Windowed.**
   Overlays cannot render on top of exclusive **Fullscreen** mode in Windows.
3. **Operating System:** Windows 10 / 11 (64-bit) for the portable `.exe`.
4. **Administrator Rights (if needed):** If you launch Path of Exile as Administrator, you must also run Simple PoE Check as Administrator; otherwise Windows blocks global hotkeys and overlay attachment.

## Quick Start (Portable)

1. Download the latest `Simple-PoE-Check-*-portable.exe` from [GitHub Releases](https://github.com/T58574/simple-poe-check/releases).
2. Place the `.exe` in any folder (for example `D:\Games\SimplePoECheck\`) and double-click it to run.
   - *Note:* Because the open-source binary is not code-signed, Windows SmartScreen may show *"Windows protected your PC"*. Click **More info** -> **Run anyway**.
3. On first launch, the workspace window opens automatically. Select your active **League** in **Settings** (or let it auto-detect the current challenge league).
4. Launch Path of Exile (in **English** and **Windowed Fullscreen**).
5. Hover over any item in game and press `Ctrl+D` to price-check it.
   - The app lives in the Windows system tray (near the clock, check the `^` overflow arrow). Double-click the tray icon to open the Stash/Farm window anytime.

## Features

- **In-Game Price Checker (`Ctrl+D`)**
  - Instant `poe.ninja` pricing for Currency (including sub-1c stack totals), Fragments, Scarabs, Beasts, Divination Cards, Uniques, Skill Gems, and Maps.
  - Live Path of Exile Trade API search for Rare, Magic, Fractured, Influenced (Shaper/Elder/Conquerors/Eldritch), and tiered `Map (Tier N)` items.
  - Supports Advanced Mod Descriptions (`Ctrl+Alt+C`), tier-aware min filters, hybrid fractured mod splitting, weapon DPS / armour Q20 estimation, quality (`Q%`), and socket/link/color (`R`/`G`/`B`/`W`) filters.
  - Proactive rate-limiter (`PolicyRateLimiter`) reading `x-rate-limit-*` headers to avoid `429` blocks.

- **Stash & Farm Tracker (`Ctrl+Space` or Pop-Out Window)**
  - **Net Worth & Tab Breakdown:** scans only the stash tabs you select and prices them locally against `poe.ninja` in Chaos and Divine Orbs.
  - **Table Filtering & Sorting:** filter by item name, category, stash tab, or minimum chaos value (`minItemChaos`), sort by any column, and click any item name to copy it.
  - **Farm Session Tracker:** take snapshots before and after mapping to measure net profit, `chaos/hr`, `divine/hr`, and top gained/lost items.
  - **Bulk Selling:** aggregates stackable/liquid items across selected tabs with configurable minimum value and price multiplier (`85%`–`110%`), ready to copy for trade.
  - **Pop-Out Window:** detach the workspace into a standard resizable OS window to move it to a second monitor.

- **Chat Macros**
  - Configurable hotkeys for `/hideout` (`F5`), `/kingsmarch` (`F6`), `@last` (`F7`), `/leave` (`F9`), and custom commands.

## Default Hotkeys

| Hotkey | Action |
|---|---|
| `Ctrl+D` | Price-check hovered item |
| `Ctrl+Space` | Toggle Stash / Farm / Bulk overlay |
| `Escape` | Close active overlay |
| `F5` | `/hideout` |
| `F6` | `/kingsmarch` |
| `F7` | `@last` (reply to last whisper) |
| `F9` | `/leave` |

All hotkeys can be customized in **Settings**.

## Privacy & `POESESSID`

- Your `POESESSID` is stored **only locally** in your Electron `userData/config.json` and is sent exclusively to `pathofexile.com` to read your selected stash tabs.
- Stash snapshots and `poe.ninja` / Trade caches are stored locally on disk.
- Clicking **Sign in (PoE)** opens `https://www.pathofexile.com/login` in your active system browser so you can copy `POESESSID` from DevTools (`F12` -> `Application` -> `Cookies` -> `pathofexile.com` -> `POESESSID`).

## Troubleshooting

- **Overlay does not appear on `Ctrl+D`:**
  - Confirm PoE is in **Windowed Fullscreen** or **Windowed** mode (not exclusive Fullscreen).
  - Confirm PoE language is **English**.
  - If PoE runs as Administrator, restart Simple PoE Check as Administrator.
  - Check **Game Window Title** in Settings (default: `Path of Exile`).
- **403 / Cloudflare error on Trade search:**
  - Add your `POESESSID` in Settings or click **Open in Browser** on the overlay card.
- **Tray icon is missing:**
  - Click the `^` arrow on the Windows taskbar; you can drag the icon onto the taskbar to keep it visible.

## Development & Build

Requires Node.js 20+ (22 recommended).

```bash
npm install
npm test
npm run build
```

Run locally after building:

```bash
npx electron .
```

Build a portable Windows executable:

```bash
npm run package:win
```

### Creating a GitHub Release

Push a version tag (`v*`, matching `package.json` version) or run the **Release** workflow manually in GitHub Actions (`Actions -> Release -> Run workflow`):

```bash
git tag v0.1.0
git push origin v0.1.0
```

GitHub Actions will run tests, package `Simple-PoE-Check-<version>-portable.exe` on `windows-latest`, generate `SHA256SUMS.txt`, and publish the GitHub Release automatically.
